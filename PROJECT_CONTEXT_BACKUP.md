## 1. Общее описание проекта

## 2. Архитектура и основные компоненты

### Модели данных (`Models/`)
- **`PluginSettings.cs`**: Главный класс конфигурации.
  - `AssemblyCodeParamName`: имя параметра для записи кода по классификатору.
  - `UndergroundParamName`: имя параметра для идентификации надземной/подземной части.
  - `IsUndergroundParamYesNo`: флаг типа параметра (true = логический Yes/No, false = текстовый String).
  - `UndergroundValueText` / `AbovegroundValueText`: значения для записи (текст или "Да"/"Нет").
  - `NeverAddBglSuffix`: глобальный тумблер (не добавлять суффикс `_BGL` для подземной части в определённых сценариях).
  - `ZeroLevel`: настройки отметок нуля здания (`ZeroLevelSettings`).
  - `Rules`: список правил классификации (`ClassificationRule`).
- **`ClassificationRule.cs`**: Модель отдельного правила.
  - `ElementTypeName`: название правила/типа элементов.
  - `RevitFilter`: фильтр элементов из Revit (`RevitElementFilterRule`) с поддержкой категорий, логических операторов (`AND`/`OR`) и набора условий (`ElementFilterCondition`).
  - `AboveGroundSearchRule` / `UndergroundSearchRule`: правила поиска в текстовом классификаторе (`ClassifierSearchRule`: слова `AllTrue`, `AnyTrue`, `Exceptions`, и бонусные баллы `ExtraTrue`).
  - `SkipAboveGround` / `SkipUnderground`: флаги пропуска классификации для надземной или подземной части.

### Сервисы и бизнес-логика (`Services/`)
- **`ConfigService.cs`**: Управление сохранением/загрузкой настроек.
  - При отсутствии конфигурации или при сбросе/загрузке профиля «По умолчанию» читает встроенный ресурс `AssemblyCodePlugin.Resources.DefaultConfig.json`.
- **`AssemblyCodeProcessor.cs`**: Основной движок обработки элементов модели.
  - Выполняет фильтрацию элементов в Revit.
  - Подбирает наилучший код из классификатора на основе рейтинговой системы (баллы за совпадения слов и штрафы/исключения).
  - Записывает значения в целевые параметры (поддерживает `String`, `Integer` для `YesNo` и `Double`).
- **`ParameterCollector.cs`**: Сбор параметров модели (с адаптацией под устаревшие типы `ParameterType` в Revit 2022 API).

### Пользовательский интерфейс (`UI/`)
- **`MainWindow.xaml` / `.cs`**: Главное окно настроек плагина.
  - Разделено на удобные карточки (Отметка нуля здания, Целевые параметры и режим записи, Таблица правил).
  - Поддерживает импорт/экспорт настроек и управление профилями конфигураций.
  - Сохранение настроек на диск происходит **исключительно по нажатию кнопки «Сохранить настройки»**.
  - Содержит панель обратной связи с ссылками на Apex и Telegram.
- **`RuleEditDialog.xaml` / `.cs`**: Окно детальной настройки и редактирования конкретного правила (фильтры Revit, условия поиска, бонусные баллы, справка).
- **`UndergroundIdentificationDialog.xaml` / `.cs`**: Окно настройки параметра идентификатора зоны (надземная/подземная) с комбобоксом (поиск параметров в модели) и адаптивными полями ввода (`String` vs `Yes/No`).

## 3. Хронология развития и ключевые принятые решения (History & Decisions)

1. **Ручное сохранение настроек**: Настройки в главном меню сохраняются только по нажатию кнопки «Сохранить настройки» (а не мгновенно при каждом чихе).
2. **Логика удаления строк**: При удалении строки из списка правил автоматически выбирается следующая строка, удаление также работает по клавише `Delete`.
3. **Кнопка «Проверить, что найдётся»**: Во вкладках настройки правил добавлена проверка работы фильтра прямо из окна редактирования.
4. **Справка по фильтрам и рейтингам**: Добавлена кнопка справки `?`, объясняющая принцип работы условий («Любое слово», «Все слова», «Исключения» по принципу `И`) и бонусных баллов (включая работу с баллом ниже нуля через слово `Подзем`).
5. **Сохранение габаритов окон**: Габариты и состояние развёртывания окон (`MainWindow`, `RuleEditDialog`) сохраняются между запусками.
6. **Панель обратной связи**: В интерфейс внедрены ссылки на Apex Messenger (`mikhail.davtyan`) и Telegram (`@Dromandon`) с фирменными иконками.
7. **Умный выбор параметров (Комбобокс с поиском)**:
   - Параметр кода по классификатору сделан выпадающим комбобоксом с поиском из Shared/BuiltIn параметров.
   - Вместо простого поля зоны сделана кнопка «⚙️ Идентификатор зоны...», открывающая специальное окно `UndergroundIdentificationDialog`. Если выбран параметр типа `YesNo`, поля ввода значений превращаются в списки `Да / Нет`.
8. **Редизайн верхней панели главного окна**:
   - Верхний блок переработан в две визуальные карточки: «🏢 Отметка нуля здания» и «⚙️ Целевые параметры и режим записи».
   - Для настройки суффикса `_BGL` внедрён современный тумблер **ToggleSwitch** с полным многострочным пояснением прямо под ним.
9. **Встраивание конфигурации по умолчанию**:
   - Пользовательский файл `По умолчанию.json` вшит в ресурсы плагина как `DefaultConfig.json`.
   - Кнопка сброса `🔄` удалена, так как профиль «По умолчанию» всегда доступен из выпадающего списка конфигураций и автоматически создаётся у новых пользователей.
